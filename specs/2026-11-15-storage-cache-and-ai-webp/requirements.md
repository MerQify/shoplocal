# Requirements — R2 storage immutable cache header and AI image WebP pipeline

Closes **#1630**.

## Context & Motivation

1. **Storage Cache Headers**: R2 custom domains (`images.merqify.com`, `images-staging.aheedfoodcentre.co.uk`) do not emit a `Cache-Control` header unless specified during object creation. Without this header, Cloudflare edge and web browsers treat image responses as dynamic (`cf-cache-status: DYNAMIC`), causing repeated re-downloads of all storefront images on every navigation.
2. **AI Image Format Optimization**: When images are generated by Workers AI (`@cf/black-forest-labs/flux-1-schnell`), raw uncompressed PNG binaries (250 KB – 500 KB each) are stored in R2 directly. By contrast, client-side uploads convert photos via HTML Canvas to WebP (`toWebp`), producing crisp ~35 KB images. Converting AI images to WebP prior to R2 persistence reduces asset weight by 85–90% with zero quality loss.

---

## Functional Requirements

### 1. Storage Service Cache Headers (`lib/storage.ts`)

- **R1.** In `lib/storage.ts`, `StorageService.putObject(key, body, contentType)` must set `cache-control: "public, max-age=31536000, immutable"` in the S3 PUT request headers.
- **R2.** In `lib/storage.ts`, `StorageService.presignPut(key, contentType, expiresInSeconds)` must sign the `cache-control` header with value `"public, max-age=31536000, immutable"`, ensuring direct-to-storage browser PUT uploads also persist the 1-year immutable cache header.
- **R3.** Existing `contentType` handling and public URL derivation in `lib/storage.ts` must remain fully backward-compatible.

### 2. Client-Side AI Image WebP Conversion

- **R4.** In `components/staff/PromotionForm.tsx`, when an administrator generates a promotional banner via AI (`handleGenerateBanner` or `handleGenerateAi`), the received image must be converted to WebP format using `toWebp` (Canvas WebP compression) and uploaded to R2 as a `.webp` asset using the established presigned PUT ticket pattern (`requestPromotionBannerUpload`).
- **R5.** The resulting stored key must end in `.webp` and the preview URL must display the optimized WebP image without full-page reloads.
- **R6.** In `app/api/admin/promotions/banner-generate/route.ts`, the endpoint must support returning the generated image payload (or binary/base64 data URL) so the client-side pipeline can convert and compress it without incurring server-side WASM/C++ runtime overhead.

### 3. Verification & Quality Gates

- **R7.** Unit tests in `tests/storage.test.ts` (or equivalent) must assert that `putObject` and `presignPut` send/sign `cache-control: public, max-age=31536000, immutable`.
- **R8.** All existing test suites, linting, typechecking, and KMS checks must pass cleanly.
